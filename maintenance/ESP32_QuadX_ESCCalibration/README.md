# ESP32_QuadX_ESCCalibration

Standalone manual ESC throttle-endpoint calibration; NEVER for flight. Remove propellers and verify ESC firmware procedure.

Open `ESP32_QuadX_ESCCalibration.ino` as a separate Arduino sketch. Do not combine with other archived programs. Remove propellers before bench work.
