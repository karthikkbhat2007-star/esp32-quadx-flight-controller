# ESP32_RC_WDT_Bench

Receiver, Wi-Fi, IMU and powered-ESC stress stages A/B/C. Flight motor control disabled.

Open `ESP32_RC_WDT_Bench.ino` as a separate Arduino sketch. Do not combine with other archived programs. Remove propellers before bench work.
